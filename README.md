# 🏦 Loan Approval Prediction using Decision Trees

A complete **Machine Learning pipeline** project that predicts **loan approval status** based on applicant details using a **Decision Tree Classifier** with hyperparameter tuning, evaluation, and deployment via **Streamlit**.

---

## 📌 Project Overview

Banks often face delays in loan processing due to manual evaluation. This project automates the **loan approval prediction process** using historical applicant data to:

✅ Speed up loan processing.  
✅ Provide quick eligibility decisions to customers.  
✅ Reduce manual operational workload.
